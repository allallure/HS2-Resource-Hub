# HS2 Resource Hub

A curated collection of simple (but maybe helpful) resources for **Honey Select 2** and **Studio Neo v2**.

> ℹ️ This hub links to original project pages — each tool retains its creator's license.

Started as a personal reference, now maintained with community feedback.

**How it works:**
- I maintain the core structure and initial files
- Links in the different list point to **original project pages** (GitHub/F95Zone)
- Users verify latest plugin versions independently from source
- Community suggestions help add/remove entries

**Have feedback or new plugins?** Join the discussion: [F95Zone Thread](https://f95zone.to/) *(add your link)*

## ⚠️ Important Notes

### Version Tracking

List in this repository work as **linked reference list**, not as installation guides. And link to **project pages**, not specific releases.
- Always access the latest version from the source
- Check each project's documentation for install instructions
- Verify compatibility with your HS2/SNv2 version
- Backup your saves before installing new plugins

### Contributing

Found broken links or abandoned or outdated plugins? Want to suggest a new addition?
- Open an issue here
- Or post in the [F95Zone Thread](link)

Community input helps keep this list useful for everyone.
