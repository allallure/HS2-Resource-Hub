# HS2 Resource Hub

A personal collection of resources for Honey Select 2 and Studio Neo v2 shared as reference material.

This repository compiles structured lists pointing to original project pages, alongside my shortcut cheat-sheet and additional guides and resources for Studio Neo v2 users. 

---

## Contents

### Link Listings

Curated lists of free and paid plugins in Markdown format to use as reference when you are new to HS2 modding or want to check if anything was recently updated. Or just when you are not sure of what plugin does what, or which are incompatible with which.

Each list includes a short description of each plugin (most descriptions are from the very developer) and a link to each plugin/project page, so you can quick-access to any aditional information or check for the last update. 

Community feedback helps add, remove, or update entries
