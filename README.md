# HS2 Resource Hub

A personal collection of resources for Honey Select 2 and Studio Neo v2 shared as reference material.

This repository compiles structured lists pointing to original project pages, alongside my shortcut cheat-sheets and additional resources for Studio Neo v2 users.

---

## Contents

### Link Listings

Curated lists of free and paid plugins in Markdown (.md) format. Use them as reference when you're new to HS2 modding, checking for updates, clarifying what each plugin does, or identifying incompatibilities.

Each list includes a table of contents for quick navigation, short descriptions (mostly from the original developers), and links to project pages so you can access additional information or verify the latest version. Important notes and warnings about bugs, special requirements, or incompatibilities are also included.

Community feedback helps add, remove, or update entries.

### Shortcut Cheat-Sheet

A wallpaper-sized cheat-sheet in multiple sizes and formats, plus the original Draw.io source file. Includes sections for Ren'Py and VSCode in case you use those tools alongside HS2.
